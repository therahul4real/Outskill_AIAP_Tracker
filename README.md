To run this, follow the command. 

1. Clone the Repository

git clone https://github.com/therahul4real/Outskill_AIAP_Tracker.git
cd Outskill_AIAP_Tracker

2. Start the Backend

cd backend
npm install
npm run dev

3. Start the Frontend

Open a new terminal:

cd Outskill_AIAP_Tracker/frontend
npm install
npm run dev

4. Backend Environment Configuration

Create a .env file inside backend/:

PORT=5001
MONGO_URI=mongodb://localhost:27017/AIAP_TRACKER

5. Required Services
Make sure MongoDB is running locally before starting the backend.
